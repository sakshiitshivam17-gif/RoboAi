# RoboSpeaker AI

A Python AI voice assistant using the OpenAI API and Linux speech synthesis.

## Features
- AI-generated responses
- Spoken answers using spd-say
- Interactive terminal chat

## Setup
1. Install Python 3 and Speech Dispatcher.
2. Create a virtual environment: python -m venv .venv
3. Activate it: source .venv/bin/activate
4. Install the SDK: pip install openai
5. Set OPENAI_API_KEY in your environment.
6. Run: python main1.py

Never publish API keys or secrets.
